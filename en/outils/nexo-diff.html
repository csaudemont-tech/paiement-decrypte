nexo/OSCAR diff - compare two terminal config files

Paste or load two files (OSCAR schema schemas.artifact.pl/oscarv4, blocks e0-f0): the comparator groups repeated blocks by their natural key (AID, RID, TAID, BIN…), detects when a record was simply moved (e.g. an application profile renumbered) instead of showing it as a separate add and remove, and decodes the already-sourced bit fields (terminalCapabilities, additionalTerminalCapabilities, TAC) using the same dictionary as nexo-config and emv-parser. Blocks with no difference stay collapsed by default.

Everything runs in your browser. Pasted or loaded files are never sent to a server - parsing and diffing run in client-side JS only. Useful since these files often contain real merchant/acquirer identifiers.

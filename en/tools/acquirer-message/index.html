This free tool decodes messages from the nexo Acquirer protocol (public nexo Standards specification, Card Payment Message Usage Guide v6.0): authorisation requests/responses, completion advice, cancellation advice. It only shows standard protocol fields and standard embedded EMV tags (ICCRelatedData), no proprietary field, no internal log format.

Ctrl+Enter to decode directly from the input field.

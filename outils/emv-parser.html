Décodeur EMV TLV

Ne décodez pas seulement les tags.
Comprenez la transaction.

Cet outil décode le TLV (tag, longueur, valeur) EMV et donne un sens étendu à chaque tag : TVR (tag 95), Terminal Capabilities (9F33), AID, dates, montants… Format décrit dans l'EMV Book 3 (Application Specification), Annexe B, règles pour les objets BER-TLV.

Ctrl+Entrée pour décoder directement depuis la zone de saisie.

Le décodage détaillé d'un seul tag, TVR, AIP, CVM Results, devise…, sans coller tout le flux. Le lien de partage fonctionne ici aussi.

    Le décodage complet tient dans l'URL, collez-la dans un ticket, un chat d'équipe ou une réponse de forum.

    Pas de tags de décision (TVR, TSI, AIP, CID, ARC…) dans ces données, la lecture de transaction s'active dès qu'ils sont présents. Essayez l'exemple « flux simple ».
